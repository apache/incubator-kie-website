OptaPlanner

A fast, easy-to-use, open source AI constraint solver for software developers.

Continuous planning​

Publish the schedule weekly, three weeks before execution, so planning keeps pace with the business rather than happening once.

Replanning​

Handle changes to an already published schedule without turning it upside down, and react to real-time disruptions within milliseconds.

Overconstrained planning​

Plan even when there are too few resources to cover all the work, so the solver degrades gracefully instead of failing.

Pinning​

Keep the user in control of the schedule by locking the parts of it that should not move.
