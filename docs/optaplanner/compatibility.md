OptaPlanner works directly from:

- Java
- Kotlin
- Scala
- Python (experimental)

OptaPlanner integrates seamlessly with:

- Quarkus
- Spring Boot

OptaPlanner runs on:

- Kubernetes and OpenShift
- All major clouds

OptaPlanner is open source software, released under the Apache License.
