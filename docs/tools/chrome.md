The Chrome extensions add a graphical editor to GitHub itself, so a model in a
pull request can be read — and edited — as a diagram rather than as XML.

- **[Apache KIE™ BPMN, DMN & Test Scenario Editors for GitHub](https://chromewebstore.google.com/detail/apache-kie-bpmn-dmn-test/mgkfehibfkdpjkfjbikpchpcfimepckf)** — visualize and edit BPMN, DMN and Test Scenario files using a graphical editor on GitHub

## Legacy

Deprecated since 10.3, with 10.2 as their final release. Still installable, but
no longer developed.

- **[Apache KIE™ Serverless Workflow Editor for GitHub](https://chromewebstore.google.com/detail/apache-kie-serverless-wor/ijamhkegfogkfnmfnfkjdiadomlphfej)** — visualize and edit Serverless Workflow files using a graphical editor on GitHub

Both are listed on the
[Chrome Web Store](https://chromewebstore.google.com/search/apache%20kie).
