[KIE Sandbox](https://sandbox.kie.org) runs the BPMN, DMN, Test Scenario and DRL
editors in a browser tab. There is nothing to install and no account to create.

It is the quickest way to open a model someone sent you, to try a change before
committing to it, or to follow along with a tutorial. Sandbox can work against
files in a GitHub repository, so a model you edit there can go back where it
came from.

- **KIE Sandbox**: [sandbox.kie.org](https://sandbox.kie.org)
