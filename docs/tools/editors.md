Embeddable builds of the editors, published to npm, for putting a modeller
inside your own web application.

- [@kie-tools/bpmn-editor-standalone](https://www.npmjs.com/package/@kie-tools/bpmn-editor-standalone) (starting from 10.2)
- [@kie-tools/dmn-editor-standalone](https://www.npmjs.com/package/@kie-tools/dmn-editor-standalone) (starting from 10.1)
- [@kie-tools/kie-editors-standalone](https://www.npmjs.com/package/@kie-tools/kie-editors-standalone) (historical — BPMN Editor (classic) and DMN Editor (classic))
